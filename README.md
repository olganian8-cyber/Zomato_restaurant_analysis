# Zomato_restaurant_analysis
## Project Overview
This project analyzes Zomato restaurant data to identity restaurant distribution popular cuisines, top cities, and online delivery trends.

## Tools Used
- Python
- Pandas
- Tableau

- ## Key Analysis
- Top cities by restaurant count
- Most popular cuisines
- Restaurant Distribution by city
- Online delivery by country
- Interactive Tableau dashboard

- ## Key Findings
- New Delhi had the highest number of restaurants.
- North Indian cuisine was most common cuisine
- Restaurant distribution varied significantly across cities.
- Online delivery availability differed by county
